# filedrawer-app

## Git workflow

- Commit each feature or fix as soon as it is done and verified (tests pass, output checked); do not leave
  finished work as uncommitted edits.
- Work on a feature branch, never directly on `main`. Keep commits small and focused.
- Stage only the files for that change; leave unrelated edits (e.g. local `fly.toml` changes) out of the commit.
- No Claude co-author lines in commit messages.
- Pushing and opening pull requests need the user's go-ahead.
